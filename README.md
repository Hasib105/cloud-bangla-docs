# Cloud বাংলা — AWS · GCP · Azure · OCI ☁️🇧🇩

এক টপিক, চার cloud। **AWS, Google Cloud, Microsoft Azure ও Oracle Cloud (OCI)** শূন্য থেকে অ্যাডভান্স —
প্রতিটি ধারণা আগে সহজ বাংলায়, তারপর চার প্ল্যাটফর্মে একই কাজ কোন service দিয়ে হয়, পাশাপাশি ট্যাবে
(Console, CLI, Terraform, মিল-অমিল, best practices, ইন্টারভিউ টিপস)।

- **মূল ধারণা** — ১৯টি অধ্যায়: IAM, compute, networking, storage, database, Kubernetes, serverless,
  messaging, observability, security, Terraform, CI/CD, data, AI/ML, cost, architecture
- **প্ল্যাটফর্ম গাইড** — AWS, GCP, Azure, OCI আলাদা করে শুরু করার গাইড
- **রেফারেন্স** — Service Map, CLI Cheatsheet, Glossary

## লোকালি চালান

```bash
pip install -r requirements.txt
mkdocs serve   # http://127.0.0.1:8000
```

[MkDocs Material](https://squidfunk.github.io/mkdocs-material/) দিয়ে তৈরি। কনটেন্ট `docs/` ফোল্ডারে।

AWS অংশের প্রাথমিক রেফারেন্স: [hrmsway/aws-bangla-docs](https://github.com/hrmsway/aws-bangla-docs)।
