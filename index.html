    এক টপিক, চার Cloud ☁️¶

    AWS · Google Cloud · Microsoft Azure · Oracle Cloud (OCI) — শূন্য থেকে অ্যাডভান্স, সম্পূর্ণ বাংলায়।

    প্রতিটি অধ্যায় আগে ধারণা বোঝায়, তারপর দেখায় একই কাজ কোন cloud-এ কোন service দিয়ে হয় — পাশাপাশি।

    এই ডকস কীভাবে আলাদা?¶

    বেশিরভাগ cloud টিউটোরিয়াল একটা প্ল্যাটফর্ম ধরে শেখায়। কিন্তু চাকরিতে গিয়ে দেখবেন কোম্পানি হয়তো Azure চালায়, ক্লায়েন্ট চায় GCP, আর আপনি শিখেছেন শুধু AWS। আসল কথা হলো — ধারণাগুলো একই। Virtual machine, network, IAM, object storage — সব cloud-এ আছে, শুধু নাম আর খুঁটিনাটি আলাদা।

    তাই এখানে আমরা শিখি টপিক ধরে:

    • ধারণাটা কী, কেন দরকার — cloud ছাড়াই, সহজ উদাহরণে
    • AWS / GCP / Azure / OCI — ট্যাবে পাশাপাশি service, Console, CLI ও Terraform
    • মিল ও অমিল — কোথায় মানুষ সবচেয়ে বেশি ভুল করে
    • একটি চলমান উদাহরণ — shopbd, একটি ছোট বাংলাদেশি অনলাইন শপ — চার cloud-এই

    আপনার cloud বেছে নিন একবার

    যেকোনো পাতায় AWS, GCP, Azure বা OCI ট্যাবে ক্লিক করলে পুরো সাইটে সেই ট্যাবই খোলা থাকবে। শুধু একটা cloud শিখতে চাইলে সেটাই বেছে নিন; তুলনা দেখতে চাইলে ট্যাব বদলান।
